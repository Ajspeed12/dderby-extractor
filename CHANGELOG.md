# Changelog

## v1.0 — first public release

- Original PlayStation TIM/RAW image extraction to PNG.
- Textured OBJ exports for tracks, starting grids, cars and menu/garage assets.
- Shared car textures, descriptive names and intact/damaged artwork.
- Six player artwork choices with 16 logical sections each.
- Ten roof, windscreen and side-window palette selections.
- Driver-specific garage trailers when the original resources are present.
- Static wheel UV repair, Y-up output and configurable scale.
- Windows BAT launcher, explicit dependency list and extraction log.

Public numbering starts at v1.0. This release packages the supplied development
build without changing its geometry, texture or palette decoding algorithms.
Known limitations and verification scope are documented in README.md.
